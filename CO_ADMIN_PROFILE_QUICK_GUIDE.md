# Co-Admin Profile - Quick Reference

## Accessing Your Profile

1. **Login** as co-admin
2. Look for **"My Profile"** in the left sidebar
3. Click to view your profile

## What You Can Do

### 📋 View Profile Information
- See your name and email
- Check your account type (Co-Administrator)
- View when your account was created
- See last update timestamp

### ✏️ Edit Your Profile
1. Click **"Edit Profile"** button
2. Update your **name**
3. Update your **email** (must be unique)
4. Click **"Save Changes"**

### 🔒 Change Your Password
1. Click **"Change Password"** button
2. Enter your **current password**
3. Enter your **new password**
   - Must be at least 8 characters
   - Include uppercase and lowercase letters
   - Include at least one number
   - Include at least one special character
4. **Confirm** new password
5. Watch the password strength indicator
6. Click **"Change Password"**

## Quick Tips

✅ **Password Strength**: Use the built-in password strength indicator to ensure your password is strong

✅ **Password Visibility**: Click the eye icon to show/hide password as you type

✅ **Email Uniqueness**: Your email must be unique across all users

✅ **Immediate Changes**: Profile updates take effect immediately

## Common Tasks

### Update Your Name
```
Profile → Edit Profile → Change Name → Save Changes
```

### Update Your Email
```
Profile → Edit Profile → Change Email → Save Changes
```

### Change Your Password
```
Profile → Change Password → Enter Current & New Password → Save
```

## Error Messages

| Error | Solution |
|-------|----------|
| "Email already taken" | Use a different email address |
| "Current password incorrect" | Re-enter your current password |
| "Passwords don't match" | Ensure new password and confirmation match |
| "Password too weak" | Follow password requirements |

## Profile Routes

- View: `/admin/profile`
- Edit: `/admin/profile/edit`
- Change Password: `/admin/profile/password/edit`

## Security Notes

🔐 **Your profile is secure**:
- Only you can edit your own profile
- Password changes require current password
- All passwords are encrypted
- Email changes are validated
