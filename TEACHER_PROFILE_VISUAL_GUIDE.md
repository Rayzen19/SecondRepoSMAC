## 📊 Data Display Priority

### Priority 1 (Main Heading):
- **Subject Name** - Most important, what teacher teaches
- **Subject Code** - Quick reference for forms/reports

### Priority 2 (Subtitle):
- **Strand** - Which track (STEM, HUMSS, etc.)
- **Section** - Which specific class

### Priority 3 (Badges/Actions):
- **Student Count** - How many students
- **View Button** - See full student list
- **Quick Peek** - Collapse/expand preview

## 🔄 Complete Assignment Flow

### Step 1: Admin assigns teacher
```
Section & Advisers Page
    ↓
[Select: 2025-2026 • STEM • Section A]
    ↓
[Assign Adviser: John Barrogo]
    ↓
[Click: Assign Teacher button]
```

### Step 2: Modal opens
```
┌────────────────────────────────────┐
│ Assign Teachers - STEM Section A  │
├────────────────────────────────────┤
│ Subject                  Teacher   │
│ Oral Communication      [Select ▼]│
│ Gen Mathematics         [Select ▼]│
│ Statistics              [Select ▼]│
│                                    │
│          [Save] [Cancel]           │
└────────────────────────────────────┘
```

### Step 3: Database saves
```sql
INSERT INTO academic_year_strand_subjects
(teacher_id, subject_id, strand_id, 
 academic_year_strand_section_id)
VALUES (1, 5, 2, 123);
          ↑           ↑
      Teacher      Section!
```
