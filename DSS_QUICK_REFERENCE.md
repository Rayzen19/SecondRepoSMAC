# Decision Support System - Quick Reference

## 🎯 What is DSS?
An AI-powered system that analyzes your academic performance and tells you exactly which assessments you need to improve.

## 📍 How to Access
Navigate to: **Student Dashboard → Performance** or visit `http://127.0.0.1:8000/student/performance`

## 🎨 Color Guide

| Color | Percentage | Status | Action |
|-------|------------|--------|--------|
| 🟢 Green | ≥90% | Excellent | Keep it up! |
| 🔵 Blue | 80-89% | Good | Almost there! |
| 🟡 Yellow | 75-79% | Needs Attention | Focus more |
| 🔴 Red | <75% | Critical | Urgent action needed |

## 🔍 What You'll See

### 1. Overall Performance Status
```
🏆 Excellent (90%+) - You're crushing it!
👍 Good (80-89%) - Solid performance
⚠️ Satisfactory (75-79%) - Room for improvement
⚠️ Needs Improvement (<75%) - Time to focus!
```

### 2. Priority Actions
Your personalized to-do list ranked by urgency:
- 🔴 **High Priority**: Fix immediately (<60%)
- 🟡 **Medium Priority**: Work on soon (60-75%)
- 🔵 **Low Priority**: Maintain excellence (≥75%)

### 3. Your Strengths
Green badges showing what you're great at (≥90%)

### 4. Areas to Improve
Red/Yellow badges showing what needs work (<75%)

### 5. Assessment Type Breakdown
Performance by:
- Quizzes
- Exams
- Assignments
- Projects
- Recitation
- Etc.

### 6. Subject Analysis
Detailed breakdown for each subject with:
- Overall percentage
- Status indicator
- Specific recommendations
- Weak assessment types

## 💡 Quick Tips

### If You're Struggling (<75%)
1. ✅ Start with ONE high-priority action
2. ✅ Talk to your teacher about weak areas
3. ✅ Form a study group
4. ✅ Review DSS weekly to track progress
5. ✅ Ask for extra practice materials

### If You're Doing Well (≥80%)
1. ✅ Focus on pushing good scores to excellent
2. ✅ Help classmates who are struggling
3. ✅ Maintain consistent study habits
4. ✅ Challenge yourself with advanced topics

## 📊 Using Filters

**Academic Year:** Select the year you want to analyze
**Term:** Choose Midterm or Finals
**Subject:** Filter by specific subject or view all

💡 *Tip: The form auto-submits when you change filters!*

## ⚙️ Understanding Recommendations

### Assessment Type Recommendations
```
"You're scoring 65% on Quizzes. Practice this type of 
assessment more frequently and review feedback from 
previous quizzes."
```
**What to do:** Take practice quizzes, review mistakes, improve time management

### Subject Recommendations
```
"Requires more focus. Review key concepts and 
practice more."
```
**What to do:** Attend tutoring, read textbook, do extra practice problems

## 📈 Tracking Improvement

1. **Baseline:** Check DSS at start of term
2. **Monitor:** Review after each major assessment
3. **Compare:** Check progress between midterm and finals
4. **Celebrate:** Watch areas move from red → yellow → blue → green!

## 🚨 When to Seek Help Immediately

Contact your teacher/adviser if you see:
- Multiple subjects in RED (<75%)
- Consistent CRITICAL status
- No improvement over several weeks
- Overall average dropping below 70%

## ❓ FAQ

**Q: How often is DSS updated?**
A: Instantly! It analyzes your latest assessment scores in real-time.

**Q: Can I see past term analysis?**
A: Yes! Use the Academic Year filter to view any previous term.

**Q: What if I have no data?**
A: You'll see a message prompting you to check when assessments are available.

**Q: Who can see my DSS recommendations?**
A: Only you! It's private to your student account.

**Q: Can I print my recommendations?**
A: Yes! Use your browser's print function (Ctrl+P).
