# Guardian Profile - Quick Reference Guide

## Access Profile
1. Login to guardian portal
2. Click **"Profile"** in sidebar (between Students and Messages)

## View Profile Information

### Profile Card (Left Side)
- Profile picture or initials avatar
- Guardian number
- Contact information (email, mobile, address)
- Account status
- Member since date

### Student List (Right Side)
- Statistics: Total students & Active students
- Table showing all linked students with:
  - Student number
  - Name and photo
  - Program
  - Grade level
  - Status

## Edit Profile

### Steps
1. Click **"Edit Profile"** button on profile page
2. Update desired fields:
   - Profile picture (optional)
   - First name *required
   - Last name *required
   - Middle name
   - Gender *required
   - Mobile number *required (format: 09XXXXXXXXX)
   - Address
3. Click **"Save Changes"**
4. Success message appears: "Profile updated successfully."

### Notes
- Email cannot be changed (contact admin)
- Mobile number must be unique
- Profile picture shows preview before saving

## Change Password

### Steps
1. Click **"Change Password"** button on profile page
2. Modal opens with form:
   - Enter current password *required
   - Enter new password *required (minimum 8 characters)
   - Confirm new password *required
3. Click **"Update Password"**
4. Success message appears: "Password updated successfully."

### Password Requirements
- Minimum 8 characters
- Must confirm current password
- New password must match confirmation

## Quick Tips

✅ **DO**:
- Keep mobile number updated for notifications
- Use strong passwords (8+ characters)
- Update address if you move
- Upload clear profile picture

❌ **DON'T**:
- Share your password
- Use someone else's mobile number
- Leave required fields empty
- Try to change email (contact admin instead)

## Common Errors

### "Current password is incorrect"
**Solution**: Double-check your password. Use "Forgot Password" if needed.

### "Mobile number already in use"
**Solution**: Another guardian is using that number. Use a unique number or contact admin.

### "Field is required"
**Solution**: Fill in all fields marked with red asterisk (*).

### "Mobile format invalid"
**Solution**: Use format 09XXXXXXXXX (11 digits starting with 09).

## Profile Picture Guidelines

- **Recommended**: Square image (same width and height)
- **Max Size**: 2MB
- **Formats**: JPG, PNG
- **Tip**: Use a clear, recent photo for better identification

## Security Features

🔒 **Your profile is secure**:
- Only you can view/edit your profile
- Passwords are encrypted
- Current password required to change password
- Session timeout after inactivity
- Secure HTTPS connection

## Need Help?

**Can't access profile?**
- Make sure you're logged in
- Check your internet connection
- Clear browser cache
- Contact admin if issue persists

**Want to change email?**
- Contact system administrator
- Provide verification for security

**Forgot password?**
- Click "Forgot Password" on login page
- Follow OTP reset instructions
